# 🧠 Quiz Game in Python

A fun and interactive **Quiz Game** made using Python! 🎮  
Test your general knowledge with 5 simple questions and see your final score.  
Perfect project for Python beginners to learn about **loops, conditions, and user input.** 💡  

---

## ✨ Features
- 🎯 5 interesting quiz questions  
- 🧩 Score tracking after every question  
- 🔁 Option to play again  
- 😎 Motivational messages based on your score  
- 👨‍💻 Beginner-friendly Python program  

---

## 🧭 How to Run
1. Open the file **`quiz_game.py`** in your Python IDE (like VS Code or IDLE).  
2. Run the program.  
3. Answer each question.  
4. View your total score at the end.  
5. Choose whether you want to play again or exit.  

---

## 💡 Technologies Used
- **Python 🐍**  
- Concepts used:  
  - `while` loop  
  - `if-elif-else` conditions  
  - `input()` function  
  - Score calculation
